# HKChat Finance

香港生活金融教育的獨立手機示範站。沿用 HKChat Legal 的品牌、深淺色介面及操作方式，法律站保持獨立。

## 五個角色入口

首頁以「角色體驗」及「生活挑戰」分頁呈現，分別有五張及四張卡片；導航使用相同分組。相近角色收在簡短選擇彈層內，各自獨立可玩。

- **中環見工記**：獨立金融模擬面試入口，選背景／履歷、五題面試、復盤指導。
- **中環職場初體驗**：返工第一日、金融新人救場記。專注新人核對資料、回覆客人、交代進度及開會發問。
- **銀行一日當值**：今日我做銀行經理、今日我做客戶經理。
- **今日我做保險顧問**：直接進入三輪虛構客戶會面，練習了解需要、解釋範圍及回應疑慮。
- **今日我做財經主播**：直接進入短講體驗，編寫講稿、接住追問及修訂說法。

五個入口涵蓋七個角色。除面試外，每個角色可輸入描述建立自訂情境，也保留兩個示範題材，約三輪／三件任務；面試擴展為背景準備、五題面試及復盤。各入口使用對應的 AI 情境照。分組設定見 `work/finance/role-groups.json`。

## 自訂情境生成演示

職場初體驗、銀行當值、保險顧問和財經主播涵蓋的六個角色，都提供「由你出題」輸入區、可點選的出題靈感，以及可返回修改的三步生成過渡。輸入 4–180 字，題材會進入本局任務、文件、客戶問題或節目稿；預設題材也經過同一過渡再開始。

這是本機靜態組合演示，沒有呼叫 LLM。不同題材使用對應的虛構練習結構；角色回應沿用選項或有限文字規則。自由輸入不會被當成已核實事實，保險自訂情境不會改寫固定練習卡的保障範圍。自訂情境、草稿與對話只留在本頁記憶體，重新整理或離開即清除；重玩同一局則保留情境設定。

共用介面及過渡位於 `work/finance/roles/scenario-generator.js` 和 `.css`；四個角色建置程式會將它們內嵌到頁面。金融面試和生活挑戰仍沿用各自的生成流程。

| 角色 | 主要互動 | 本局成果 |
| --- | --- | --- |
| 今日我做銀行經理 | 調整分行安排，聽三方意見，再修訂 | 分行服務方案、待跟進問題 |
| 中環見工記 | 選背景／本機讀取履歷，五題面試與可選追問 | 引用原答的復盤、單題重練及文字筆記 |
| 返工第一日 | 處理收件匣：摘要、客人回覆、匯報 | 交更紀錄 |
| 今日我做客戶經理 | 查事實卡，回應客人疑問 | 對話紀錄與跟進事項，可複製 |
| 今日我做保險顧問 | 問需要、講範圍與限制、回應疑慮 | 逐輪會面紀錄、單輪重練及可複製筆記 |
| 今日我做財經主播 | 編寫短稿，接觀眾追問，再修訂 | 文字節目稿，可複製 |
| 金融新人救場記 | 選介入方式、查依據、改會議投影片 | 修訂頁及會議跟進紀錄 |

角色回應按預設選项或關鍵字分支變化，無法配對的自由輸入保留原文並清楚標示未評估。面試不提供錄取預測或招聘評分；主播只產生文字稿，不宣稱錄音。所有角色的服務安排、文件、消息及人物均屬虛構，結果是本局練習紀錄。

「金融 App 主理人」及「財經消息查證官」已從首頁及導航移除。舊網址 `hkchat-product-mobile.html` 轉往保險顧問，`hkchat-verify-mobile.html` 轉往財經主播；兩頁只保留轉址及替代連結。

## 保險顧問模擬

`hkchat-insurance-mobile.html` 提供兩位虛構客戶：剛入職、想了解門診與牙科分別的阿晴，以及準備週末小旅行、想了解活動限制的阿朗。每次會面約三分鐘，共三輪：先問需要，再講清範圍及限制，最後回應疑慮、尊重客戶選擇。

- 每輪有三句預設說法，提交後顯示對應的客戶接話及練習提示；可展開虛構事實卡核對依據。
- 自訂或改寫文字會原樣保留。除非完全配對預設句子，否則不評估內容、不推斷客戶反應，結果中標示「待覆核」。
- 可提早收尾或繼續未完成的會面；復盤逐輪記錄實際回答，單輪重練保留原本及重練版本，筆記可複製。

此體驗使用預設內容，沒有即時 AI 對話、銷售成績、產品推薦、金額或交易。練習卡不是實際保單，不判斷承保或索償結果。會面只存在目前頁面的記憶體內，不寫入 localStorage／sessionStorage；刷新或離開頁面即清除。保監局資料連結只作一般概念參考。

## 金融模擬面試

`hkchat-interview-mobile.html` 是面向金融行業的三階段模擬面試，可練習銀行業務培訓生或風險管理分析員。主線使用「香港科技大學畢業生 · AI × 金融學習背景」的虛構人物；AI × 金融只描述這位候選人的履歷，不是面試產品的專業限制。也有金融系及轉職示範背景，或可使用自己的履歷。示範人物並非特定學位名稱、院校推薦或真實校友紀錄。

- **準備背景**：PDF、DOCX、TXT 可在瀏覽器讀取（5 MiB、PDF 前十頁），也可貼文字或手動填寫。先核對摘錄內容，缺失資料不會補成示範人物。
- **模擬面試**：求職動機、經歷深挖、業務判斷、專業操守、溝通協作五題；每題最多一次追問，可提早收尾。支援中文或英文文字作答。
- **指導與重練**：有限文字規則找出實際回答中的線索並逐句引用，提供改善方向及參考結構；未回答或無法辨認的內容不評估。單題重練保留兩版，復盤可複製或下載。

面試仍是靜態演示，沒有即時 LLM、語音面試、錄取預測或能力分數。上傳內容不離開瀏覽器，也不寫入 localStorage／sessionStorage；重新整理或離開頁面即結束這份記憶體內的面試。PDF.js 與 fflate 已固定版本、自包含並保留授權，詳見 `work/finance/interview/vendor/README.md`。掃描、加密及不可讀文件會提供貼文字的回退；Chrome 直接以 `file://` 開啟時，請用文字路徑或從網站連結開啟 PDF 功能。

## 四個生活挑戰

- **財智快打**：三個話題、每局五關、條件變化題及演示 PK。配對、計分及結果頁使用提供的兩張人像作占位頭像，圖片內嵌於頁面。
- **金融大找茬**：三張 AI 生成的銀行／保障／群組場景，每幕三個可點選的細節。
- **金融細字挑戰**：三個基本情境、三個額外模板、五條細字、追問與結果解說。
- **金融防騙局**：三個領域、六個虛構故事、最多五輪、角色專屬問題與自由輸入。

所有體驗均為虛構金融教育材料，沒有金額、付款、模擬資產、收益計算、產品推薦或真實交易功能。引用 HKMA、IFEC 或其他官方教育資料不代表機構認可本示範。

這是靜態示範：AI 圖片已預先生成；情境配對、題目變化與角色回應使用預設內容。PK 使用程式模擬對手，沒有多人連線或即時模型後端。刷新會清除本金融站的進度；部分體驗在一般頁面跳轉時保留進度，面試及保險顧問只保留於當前頁面記憶體。

## 預覽與重建

`site/` 是可直接部署的靜態站。各 HTML 已內嵌圖片和執行程式，沒有執行時 CDN 或 API 依賴。

```sh
python3 -m http.server 8765 --directory site
```

重建需要 Python 3 和 Pillow：

```sh
python3 -m pip install Pillow
python3 build.py
```

可編輯來源位於 `work/finance/`，角色來源位於 `work/finance/roles/`，新版面試位於 `work/finance/interview/`，保險顧問位於 `work/finance/insurance/`；共用與找茬圖片位於 `outputs/`。生成圖片的提示詞保存在 `work/finance/image-prompts.json`、`image-hero-prompt.json` 及 `roles/image-prompts.json`。保險顧問照片為 `outputs/hkchat-finance/assets/role-insurance.webp`，提示詞及生成資料為 `work/finance/insurance/image-prompt.json`。HKChat 標誌沿用原站官方素材，沒有重新繪製。

## 發布

GitHub Actions 從 `main` 分支的 `site/` 發布至 GitHub Pages。本站獨立於 `chenqianwan/hkchat-legal`。

目前發布十二個有效頁面（首頁、七個角色及四個生活挑戰），另有兩個舊網址轉址頁。

驗證涵蓋角色流程、選擇分支、自訂文字、提早結束、重玩、成果複製，以及首頁分頁、玩法彈窗、角色選擇、分組導航和刷新儲存範圍。保險顧問另檢查兩位客戶的逐輪預設回應、未評估自訂文字、續玩、重練保留原答及舊網址轉址。介面檢查使用手機 320／390／430 寬度、深淺色及 Chromium／WebKit。原四種遊戲的核心資料和邏輯維持原版；找茬圖片熱點已經整合回歸檢查。WebKit 為瀏覽器引擎測試，並非實體 iPhone 測試。
